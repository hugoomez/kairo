# Kairo plugin — rules for working in this repo

- **This repo is public. Research content never goes in it.** Audits,
  evaluations, and any file that quotes a project's claims, hypothesis text,
  experiment results, or paper text (abstracts, excerpts, `## Texto completo`)
  live in the vault only (`Kairo/vault/Audits/` for audits). That includes
  audits of how the plugin behaved on a real vault. Write them there, commit
  them in the vault repo, and never push the vault.
- Tests and examples use invented ids and invented text, never content copied
  from a vault note.
